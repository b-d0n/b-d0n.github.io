To use:
1. Copy index.html and style.css into your engineering-portfolio folder.
2. Double-click index.html to preview it in your browser.
3. Replace the placeholder text as we build each section.
4. Images can be added later in an images/ folder.
5. The Resume button is currently a placeholder. Later put your resume PDF in the folder and set its href.

No frameworks, installs, or JavaScript are required.
